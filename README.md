Leonida Ledger is an offline guide and tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI. Every trophy appears with its official name, description and grade exactly as PlayStation publishes them, and beside each one sits a guide written for this page in our own words — what to do, where it happens, and when it can be missed — with its sources named next to it, because a cited guide beats an uncited one. The one trophy that can be missed, Positive Mental Attitude, is flagged wherever it appears.

The guide is built around a five-phase platinum roadmap (difficulty 4/10, roughly 200 hours, a single playthrough) that opens with the chapter-save habit the game's lack of mission replay demands and the warning that cheats disable trophies and saving, then walks the story, the 100% completion checklist, the strangers and character cleanup, and the money trophies that close the list out. A spoiler shield masks the 28 secret trophies — names, descriptions and guides — until you mark them earned, so the checklist is safe to browse before finishing the story.

It is a tracker as well as a guide: tick trophies off as you earn them and the header keeps your count, your PlayStation points out of the list's 1,350, and a progress bar, while kind chips, a grade filter and search narrow the shelf. Progress is saved in the browser's localStorage and can be exported to a JSON file and imported back on another machine. The app itself is plain HTML, CSS and JavaScript plus one data file under app/ — no build step, no accounts, and no network requests at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Any static file server with app/ at its root works just as well.
